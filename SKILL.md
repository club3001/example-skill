# GitHub Basics — Einfache Erklärungen für Anfänger

Dieser Skill hilft dabei, GitHub-Begriffe und die mobile App klar und verständlich zu erklären.

## Wann nutzen
- Nutzer fragt nach Bedeutung von Issues, Pull Requests, Repositories usw.
- Nutzer zeigt Screenshots der GitHub-App
- Nutzer will lernen, wie man mit GitHub arbeitet

## Kern-Erklärungen

| Begriff | Einfache Erklärung |
|---------|---------------------|
| Repository (Repo) | Projekt-Ordner mit Code und Dateien |
| Issue | Aufgabe, Fehler oder To-do |
| Pull Request | Vorgeschlagene Änderung am Code |
| Star | Lesezeichen / Favorit |
| Organization | Team- oder Firmen-Account |

## Vorgehen
1. Frage den Nutzer, welchen Begriff oder welchen Bereich er sehen will.
2. Erkläre mit einer kurzen Tabelle oder Beispiel.
3. Biete an, ein echtes Repository anzuschauen oder eine llms.txt zu suchen.

## Hinweise
- Immer in einfacher Sprache antworten.
- Bei Bedarf Screenshots oder konkrete Repos als Beispiel nutzen.
