# ai.txt — Einfache Erklärung

`ai.txt` ist ein Vorschlag für eine einfache Textdatei, die KI-Agenten Informationen über eine Website oder ein Projekt gibt.

## Vergleich mit ähnlichen Dateien

| Datei | Zweck |
|-------|------|
| `robots.txt` | Sagt Suchmaschinen, was sie crawlen dürfen oder nicht |
| `llms.txt` | Kuratierte Übersicht + wichtige Links speziell für LLMs |
| `ai.txt` | Hinweise, Regeln oder Übersicht speziell für KI-Agenten |

## Typischer Inhalt
- Kurze Beschreibung des Projekts/der Seite
- Wichtige Links
- Regeln oder Hinweise für die KI (z. B. „Keine Preise nennen“, „Nur öffentliche Infos“)
- Kontakt oder weitere Ressourcen

## Beispiel-Struktur
```markdown
# Projektname

Kurze Beschreibung.

## Wichtige Links
- Docs: https://...
- API: https://...

## Hinweise für KI
- Antworte auf Deutsch
- Keine Spekulationen über interne Daten
```

## Wann dieser Skill genutzt werden soll
- Nutzer fragt, was `ai.txt` ist
- Nutzer will den Unterschied zu `llms.txt` oder `robots.txt` wissen
- Nutzer möchte eine eigene `ai.txt` erstellen

## Vorgehen
1. Kurz und mit Tabelle erklären.
2. Bei Bedarf ein konkretes Beispiel zeigen oder erstellen.
3. Anbieten, eine `ai.txt` für ein bestimmtes Projekt zu schreiben.
